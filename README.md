# Web Programming (HTML/CSS/JS) exercises
This repo contains several web pages used for exercising with various aspects in these three languages used in web frontend development

Web Programming 2022 homework

## Repo Structure
- L1 - HTML - conversion of C801 form into a web form (contains just structure)
    - HTML5 version of the form
    - HTML4 version of the form
    - both variants are compliant to their respective standards and result in no warnings upon parsing
- L2 - CSS
    - P1 - center-aligned text and image, each in their own box of same dimensions
    - P2 - webpage layout example with horizontally aligned menu items
    - P3 - webpage layout example with vertically aligned menu items
    - P4 - social icons with on-hover effect using a spritesheet
    - P5 - gallery using a list with figure elements laid out in a grid
    - P6 - text input fields stylized for one character per square
    - P7 - list of messages stylized similar to an instant-messaging app
 - lab_js (L3) - JS
    - P1 - two select lists, double click to move elements from one to the other
    - P2 - form validation with user-friendly visual cues
        - name not null
        - birthday not null
        - age not null, between 18 and 150
        - valid email (regex)
    - P3 - randomly laid oud memory match game
        - variant 2 picks from a list of images
    - P4 - sortable tables, vertical and horizontal headers
    - P5 - image/hyperlink carousel with auto-next, transition animation and previous/next buttons
